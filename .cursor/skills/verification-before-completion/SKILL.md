# Verification before completion

Never claim done without:

1. Card AC checked
2. Listed validation commands run (paste short output in `evidence/`)
3. Anti-leak skim on touched files
4. Tests/smoke relevant to diff
5. Formal docs updated only if decision/contract changed

If verification fails → status stays `in_progress`; fix or open follow-up card.
