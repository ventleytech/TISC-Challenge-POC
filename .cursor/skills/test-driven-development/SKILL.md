# TDD (VoltPulse)

1. Write failing test or contract assertion from card AC.
2. Implement minimum to pass.
3. Refactor; keep green.
4. Record test command + result in card `evidence/`.

Skip pure scaffolding (empty Compose stub) if card says smoke-only — still capture smoke evidence.
